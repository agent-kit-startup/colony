# Contributing

Colony is licensed under the [Apache License 2.0](LICENSE). Contributions are accepted under the same license.

## Developer Certificate of Origin

From the first Apache-2.0 release (v0.1.0), every commit in a pull request carries a `Signed-off-by:` line from the person who submits it, certifying the [Developer Certificate of Origin 1.1](https://developercertificate.org/):

```bash
git commit -s
```

There is no CLA. Sign-off is checked at review; there is no DCO bot or CI step. If an agent wrote the change, the human who submits it signs off.

## Names and logo

The license covers the code, not the names "Mission Kit", "Agent Kit" or the helmet logo. A published modified version uses another name and logo. See the Agent Kit [names and logo policy](https://github.com/agent-kit-startup/agent-kit/blob/main/TRADEMARKS.md).
